# hardware

| Path | Contents |
|---|---|
| `cad/` | Source models and printable parts (STL, STEP) |
| `print/` | Print-ready Bambu Studio plates 01 to 25 for the statue and plinth, with the print plan and the assembly card |
| `enclosure/` | Plinth, refill hatch and mounting drawings |
| `wiring/` | Wiring diagrams and the pin map |

Every part is printed in PLA+, the candy path included, and used only with individually wrapped sweets. PLA+ softens at about 55 to 60 °C, so keep the gargoyle out of direct sun. The part list is in [docs/bill-of-materials.md](../docs/bill-of-materials.md).
